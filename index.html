Створення тематичної вебсторінки

Розробка стандартної DOM-структури документа без зовнішнього CSS. Використання форматування тексту згідно з варіантом 3 (Таблиця 2), метадані, 3-4 фотографії різного масштабу та система гіперпосилань.

  • Фото 100%, 50%, 20% (в корені та у images/)
  • Зовнішні, внутрішнє посилання та фото-посилання

Стилізація CSS тематичної сторінки

Стилізація тексту та графічних об'єктів за допомогою вбудованої таблиці стилів (тег <style>). Реалізація специфічних рамок, шрифтів, кольорів та інтерактивних hover-ефектів.

Вимоги за Варіантом 3:
  • Вбудована таблиця стилів (тег <style>)
  • Times New Roman 19px, синій текст, світло-сірий фон
  • Межа тексту: тримірна inset 50px gray, border-radius
  • Фото 1: кругле border-radius 60% із сірою межею
  • Фото 2: hover (scale, double 30px зелена межа, тінь)

Розробка фрагменту Веб-сайту

Повноцінний фрагмент сучасного сайту з семантичними тегами Header, Footer, Nav на кнопках та Main Content. Окремий файл стилів style.css з реалізацією розширених властивостей CSS.

Вимоги за Варіантом 3:
  • Окремий файл style.css та семантика HTML5
  • 1) Плаваючі елементи (властивість float)
  • 2) Оптимізований CSS-спрайт (sprite.png)
  • 3) Тіні для об’єктів (box-shadow)
  • 4) Фонове зображення з повторенням (repeat)
  • 5) Напівпрозорий фон блоків (rgba)
